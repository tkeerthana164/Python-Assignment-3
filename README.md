Python Assignment 3 – Loops and Functions

📌 Overview

This repository contains my third Python assignment, focusing on loops, control statements, and functions. The assignment helped me practise Python programming through simple, practical programs.

📚 Topics Covered

1. While Loop – Number Guessing Game

Generate a random number using random.randint().

Allow the user to guess the number within 3 attempts.

Check whether the guess is too high or too low.

Handle invalid guesses using continue.

Use break when the correct number is guessed.

Use else with the while loop when attempts run out.

2. For Loop – Multiplication Table Generator

Accept a number from the user.

Generate its multiplication table from 1 to 10.

Use a for loop and the range() function.

Display the multiplication results.

3. Functions – BMI Calculator

Define a function named calculate_bmi(weight, height).

Accept weight in kilograms and height in metres.

Calculate BMI using the formula:

BMI = Weight (kg) / Height (m)²

Return the calculated BMI using return.

Display the result up to two decimal places.
